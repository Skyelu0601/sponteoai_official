# 小栗头盘串隐私政策

版本生效日期：2026 年 8 月 26 日

上海自在纪元科技有限公司（以下简称“我们”）重视您的个人信息与隐私保护。本政策说明您使用“小栗头盘串”移动应用（以下简称“本服务”）时，我们如何处理个人信息，以及您如何行使相关权利。请在使用本服务前仔细阅读。

## 一、我们处理的信息

我们仅在提供相应功能所必需的范围内处理下列信息；您不使用相关功能时，我们不会因该功能处理对应信息：

1. 账号信息：手机号、短信验证码验证结果、登录凭证，用于注册登录、身份校验和账号安全。验证码仅用于验证，不会以明文长期保存。
2. 文玩档案与用户内容：您主动拍摄、选择或填写的照片、名称、分类、标签、盘玩记录、日期和备注，用于建档、展示、云端同步和生成对比图。照片上传前可能被压缩、裁剪并移除部分元数据。
3. 会员与交易信息：会员状态、商品编号、订单号、交易号、支付状态，以及 Apple 提供的票据、华为提供的签名订阅凭据或支付宝返回的支付结果，用于开通权益、校验交易、处理未到账及售后。我们不收集或保存完整银行卡号、华为账号密码、支付宝账号密码等支付账户信息。
4. 设备与运行信息：App 版本、设备型号、操作系统版本、网络状态、请求时间、IP 地址和必要的错误日志，用于兼容适配、故障排查、安全风控和防止接口滥用。通过“意见反馈”发送邮件时，App 版本和基础设备信息会随用户可见的邮件正文一并提供。
5. 本地偏好信息：隐私同意版本、登录状态、提醒开关与时间、评分提示状态和待确认订单号，用于保持您选择的设置。退出或注销账号时会清除与账号关联的提醒目标和待确认订单状态。

## 二、设备权限与调用时机

我们遵循“功能触发时申请、拒绝后可继续使用其他功能”的原则：

1. 相机：您点击拍照建档或新增记录时调用，用于拍摄文玩照片。拒绝后无法拍照，但仍可使用系统相册选择器。
2. 系统照片选择器：您主动选择照片时调用，只读取您本次选中的照片。拒绝后无法从相册选择照片；Android 不申请全量相册读取权限。
3. 添加到相册/旧版存储：您主动保存对比图时调用；Android 9 及以下可能申请存储权限。拒绝后无法保存到系统相册，不影响应用内记录。
4. 通知：您主动开启“每日盘串提醒”时调用，用于在设备本地安排提醒。拒绝后不会收到提醒，不影响其他功能。
5. 网络：您同意本政策并使用登录、同步、支付等联网功能后调用，用于访问我们的服务及您主动使用的第三方服务。不可用时，登录、云同步和支付等联网功能会受影响。

Android 与 HarmonyOS 首次启动时，在您同意本政策前，我们不会初始化联网账号、支付、评分或通知服务，也不会申请相机、照片或通知权限。

## 三、信息的使用方式

1. 提供账号登录、文玩建档、拍照记录、云端同步、图片导出和会员权益。
2. 处理交易校验、权益发放、订单查询、退款或未到账协助。
3. 进行兼容适配、故障排查、安全风控和服务质量改进。
4. 发送您主动开启的本地提醒，以及法律法规要求或政策重大变化等必要通知。未经另行同意，我们不会将通知用于商业营销。

## 四、第三方服务与 SDK 清单

我们不会出售或出租您的个人信息。为实现必要功能，我们可能向下列服务提供实现该功能所必需的信息：

1. 阿里云短信 / 阿里云计算有限公司：通过服务端接口接入，不嵌入客户端。用于发送登录验证码，可能处理手机号、验证码模板参数、发送结果和 IP 地址。
2. 阿里云对象存储 OSS / 阿里云计算有限公司：通过服务端接口接入，不嵌入客户端。用于存储并展示您主动上传的照片，可能处理照片文件、对象标识、访问签名和 IP 地址。
3. Apple App Store / Apple Inc.：通过 iOS 系统 StoreKit 接入。用于 iOS 会员订阅、恢复购买和票据校验，可能处理商品编号、交易号、票据信息和订阅状态。
4. 支付宝客户端 SDK / 支付宝支付科技有限公司：Android 客户端版本 15.8.42，用于完成会员支付，保障账户、资金与支付安全，履行反洗钱、反诈义务并优化网络链路。仅在您点击支付宝购买并进入支付流程时调用。SDK 可能在设备本机自动采集订单号、商品名称、金额，Android ID、OAID、AAID，设备系统设置与属性、型号、品牌、操作系统，传感器信息（传感器列表）、屏幕密度、运营商信息、IP 地址、网络类型，以及 Wi-Fi 状态、参数和列表（可能包含 SSID、BSSID）；还会查询是否安装支付宝、淘宝等受支持客户端。实际可取得的字段受 Android 版本、系统权限和设备能力限制。SDK 使用 INTERNET、ACCESS_NETWORK_STATE、ACCESS_WIFI_STATE 等网络能力，通过加密网络将必要信息直接传输至支付宝并由支付宝独立存储和处理。我们的服务端接收订单号、交易号、金额和支付状态用于验签及发放权益，不接收您的支付密码或完整支付账户信息。
5. 华为 IAP Kit / 华为软件技术有限公司：仅在 HarmonyOS 会员页查询商品、恢复购买或您主动购买时调用，用于展示商品和华为收银台、处理自动续期订阅。可能处理华为账号所对应的支付地区、商品编号、购买 Token、订单号、订阅状态、到期时间及华为签名凭据。我们的服务端仅接收完成验签和发放权益所需的上述交易信息，不接收华为账号密码或完整银行卡信息。

支付宝支付由您主动触发，支付宝对信息的处理同时受其向您展示的协议和隐私政策约束。支付宝 SDK 官方隐私说明：https://opendocs.alipay.com/open/54/01g6qm 。小米应用商店可能在下载、安装和更新环节按其规则处理必要信息，该过程由商店独立提供。

## 五、存储、保护与保存期限

1. 业务数据存储于中华人民共和国境内的服务器和对象存储，并通过加密传输、访问控制和日志审计等措施保护。
2. 我们仅在实现上述目的所必需的期限内保存信息。账号存续期间保留您主动创建的档案与记录；您删除单条记录或注销账号后，我们将删除或匿名化相应业务数据，但法律法规要求留存的交易、安全和审计信息除外。注销后，为使注销前签发的登录凭证全部失效，我们会保留不含业务内容的账号安全撤销标记，最长不超过原登录凭证的 180 天有效期，期满自动删除。
3. 登录凭证存放于设备安全存储。Android 已关闭系统自动备份，避免账号数据被系统备份迁移。
4. 如发生个人信息安全事件，我们将依法采取补救措施，并按规定告知用户和主管机关。

## 六、您的权利

1. 访问与更正：可在应用内查看、修改文玩档案和账号相关信息。
2. 删除与注销：可删除单条记录，也可在“用户中心—注销账号”中申请注销并删除与账号关联的数据。
3. 撤回同意或权限：Android 与 HarmonyOS 可在“用户中心—隐私授权管理”撤回隐私同意并退出；也可前往系统设置关闭相机、照片或通知权限。撤回不影响此前基于同意进行处理的效力。
4. 获取副本与投诉：可通过客服邮箱联系我们，申请访问、更正、删除或获取个人信息副本，并反馈隐私问题。

我们将在核验身份后于法律规定或合理期限内处理请求；无法满足时会说明原因。
